The web fonts in this folder are Adobe's Source Sans and Source Serif variable fonts, as bundled
with InDesign (SourceSansVariable-Roman/-Italic.otf, SourceSerifVariable-Roman.otf), repackaged
unchanged as WOFF 1.0 (zlib-compressed tables) by _build/assets.py. Web names: Source Sans 3, Source Serif 4.
